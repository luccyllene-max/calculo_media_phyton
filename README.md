# Calculadora de Média do Aluno

Este projeto foi desenvolvido em Python para calcular a média de duas notas de um aluno e informar se ele foi aprovado ou reprovado.

## 1. Calculadora de Média

O programa solicita duas notas, calcula a média e apresenta o resultado.

*Exemplo:*

- Primeira nota: 7
- Segunda nota: 8
- Média final: 7.0
- Status: APROVADO
